REFEREE PROJECT — BRAND KIT (v1, November 2026)

Colors
  Ink navy    #17295C   tile, wordmark
  Sky blue    #8FB2E3   brackets on navy
  Slate blue  #3F6AA8   "PROJECT" on light backgrounds, links
  Pale blue   #A9C3E8   "PROJECT" on dark backgrounds
  Paper       #F7F5F0   page background
Fonts: Source Serif 4 (wordmark, tagline), Inter (PROJECT, interface text).
Tagline: Adding quality and nuance to the scholarly record.

Files
  referee-symbol.svg / .png        The [R] tile. PNG is 1024 x 1024.
  referee-horizontal.svg / .png    Symbol + "Referee Project", for light backgrounds.
  referee-horizontal-white.svg     For dark backgrounds.
  referee-horizontal-navy.svg      One color (navy). The R and brackets are cut-outs.
  favicon.svg / favicon.ico        Browser tab icons (thicker drawing for 16-32 px).
  apple-touch-icon.png             180 x 180, for iPhone and iPad home screens.
  icon-512.png                     Android home screens and social profile pictures.
  og-image.png                     1200 x 630 link preview (LinkedIn, Slack, X).

All text in the SVG files is converted to outlines. No fonts are necessary.

HTML <head> tags for the website (put the files in the site root):

  <link rel="icon" href="/favicon.ico" sizes="any">
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">
  <meta property="og:image" content="https://referee-project.com/og-image.png">
  <meta property="og:image:width" content="1200">
  <meta property="og:image:height" content="630">
  <meta name="twitter:card" content="summary_large_image">
